## 🚀 Project Overview

This project was developed as part of the software engineering assessment for **Storewise**. The core objective was to take a foundational UI and engineer a robust, fully functional task management system. The application allows users to seamlessly create, track, update, and persist their daily tasks with an emphasis on a frictionless user experience.

---

## ✨ Features Implemented

The development process was structured into two progressive milestones, all of which have been successfully implemented:

### 🟢 Level 1: Core Functionality
- **Dynamic Task Management:** Create, read, update, and delete (CRUD) tasks instantly.
- **Detailed Task Views:** Expanded UI states to view comprehensive task details.
- **Status Tracking:** Mark tasks as complete/incomplete with visual UI feedback.
- **Data Persistence:** Integrated `LocalStorage` to ensure user data remains intact across browser sessions and reloads.
- **Dynamic Header:** Real-time UI updates reflecting current application state.
- **UI Enhancements:** Improved styling, transitions, and layout for a polished, professional feel.
- **System Debugging:** Resolved existing architectural bugs from the starter template.

### 🔵 Level 2: Advanced State & Features
- **Task Renaming & Editing:** In-line editing capabilities for rapid task modification.
- **Task Cloning:** Implemented deep-copy logic to allow users to duplicate existing tasks with a single click.
- **State Refactoring:** Overhauled the initial state management approach to ensure scalable, predictable data flow across components.

## ⚙️ Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites
Ensure you have the following installed:
* [Node.js](https://nodejs.org/) (v14.0.0 or higher)
* [npm](https://www.npmjs.com/) (v6.0.0 or higher)

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/achalagarwal/storewise-engineering-assignment.git](https://github.com/achalagarwal/storewise-engineering-assignment.git)
   cd personal-task-management-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the app:**
   Open `http://localhost:5173` (or the port provided by Vite) in your browser.
